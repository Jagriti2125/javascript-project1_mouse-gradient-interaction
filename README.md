# Mouse Gradient Interaction 🎨

An interactive JavaScript project where a rectangle dynamically changes color based on mouse movement.

## 🚀 Features

- Left side → More red
- Right side → More blue
- Center → Mixed gradient
- Real-time mouse tracking
- Smooth RGB transition

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📚 Concepts Learned

- DOM Manipulation
- Mouse Events
- Event Listeners
- RGB Colors
- Dynamic Styling
- getBoundingClientRect()
- Mouse Position Calculation

## 🎯 Project Goal

Built this project while learning JavaScript and DOM interactions.
